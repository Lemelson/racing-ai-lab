# AI car sprite

Файл: `ai-car-topdown.png`

Создан встроенным ImageGen как локальный game asset.

Финальный prompt:

```text
Use case: stylized-concept
Asset type: top-down 2D racing game car sprite
Primary request: a compact futuristic training car viewed perfectly from directly overhead, designed for an AI learning simulator
Scene/backdrop: genuinely transparent background
Subject: one symmetrical low-profile car with a rounded capsule-like silhouette, clear front and rear, dark tinted cockpit, four subtle wheel shapes, a central white body with neutral gray details so the game can tint it red, green, blue, or amber
Style/medium: polished 2D game sprite, crisp slightly soft vector-like raster rendering, readable at 48–96 pixels
Composition/framing: perfectly centered, nose pointing straight upward, orthographic top-down view, generous transparent padding, no perspective angle
Lighting/mood: restrained soft studio shading, no cast shadow outside the silhouette
Constraints: actual transparent alpha background; single car only; no sensor rays; no text; no logo; no number; no watermark; no scenery; no border; strong clean silhouette
```

PNG содержит alpha channel. В Canvas участник получает цветной glow, а общий белый корпус сохраняет единый визуальный стандарт.
