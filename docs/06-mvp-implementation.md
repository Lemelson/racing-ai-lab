# Рабочий 2D MVP

Дата проверки: 26 августа 2026 года.

## Интерфейс

В продукте сейчас два раздела:

1. `Трассы`
2. `Симуляция`

Не реализованные `Алгоритмы`, `Запуски`, `Replay` и comparison/fairness больше
не выдаются за готовые страницы. ChatGPT и Gemini не отображаются как участники,
пока для них нет настоящего независимо созданного кода.

Дизайн выбран после сравнения пяти ImageGen-концептов. Эталонные изображения и
извлечённая система лежат в `references/ui-concepts/`.

## Редактор трасс

- Полноэкранный 2D-холст с pan, wheel zoom и `Показать всю трассу`.
- Инструменты `Маршрут`, `Ширина`, `Ластик`, `Перемещение`.
- Рельеф спрятан под честной пометкой `экспериментально`.
- Сырые pointer-события не являются контрольными точками.
- После каждого жеста линия пересэмплируется через одинаковое расстояние. Поэтому
  быстрый и медленный ввод одной геометрии дают одинаковые точки.
- Следующий штрих присоединяется к ближайшему началу или концу. Несвязанные
  фрагменты остаются видимыми и не проходят завершение.
- Ластик разбивает маршрут на отдельные фрагменты и не создаёт скрытый chord.
- Ширина и elevation хранятся локально в точках и интерполируются по сегменту.
- Undo/redo держит двадцать действий.
- До `Завершить и сохранить` нет compiled course, checkpoints, progress или
  fitness. На холсте видны только дорога и её синие концы.
- При завершении сглаживание один раз запекается в реальные точки. Renderer и
  физика используют одну геометрию.
- Каталог хранит неизменяемые версии с checksum, включая `width` и `elevation`.

## Машина и обучение

- Fixed-timestep 2D kinematic vehicle.
- Управление: steering `[-1, 1]`, throttle `[0, 1]`, brake `[0, 1]`.
- Семь лучей: `−90°, −60°, −30°, 0°, +30°, +60°, +90°`.
- Восьмой вход — normalized speed.
- Сеть `8 → 10 → 3`, `tanh`, 123 параметра.
- Детерминированный seeded RNG.
- Rank selection, crossover, mutation и elitism.
- Единственный видимый участник — `Базовый эволюционный алгоритм`.
- UI показывает реальные replay текущей популяции, а не декоративные копии:
  лучшая машина синяя, остальные приглушены.
- Доступны Start, Pause/Resume, Stop и обычная/быстрая скорость.

## Fitness

- Reward начисляется только за подтверждённый forward progress.
- Повтор позиции и движение назад не дают положительный reward.
- Speed bonus требует нового forward progress.
- Слишком большой jump отклоняется.
- Finish-line wrap распознаётся.
- Off-track движение не накапливает progress и получает collision penalty.
- Количество исходных точек мыши не влияет на reward: progress основан на
  непрерывном `distanceAlong` готовой трассы.

## Проверка

Автоматические проверки:

```text
50 tests passed
syntax check passed
```

В реальном локальном браузере проверено:

```text
Трассы
→ Создать трассу
→ pointer-жестом нарисовать замкнутый маршрут
→ Завершить и сохранить
→ открыть сохранённую трассу в Симуляции
→ Запустить обучение
→ увидеть изменение generation/progress/fitness/steps
→ Пауза
→ подтвердить, что поколение не меняется
```

Console errors и warnings: `0`.

## Что ещё не реализовано

- Настоящие отдельные решения ChatGPT и Gemini.
- Несколько training/validation трасс в одном запуске.
- Сохранённая библиотека replay и run artifacts.
- Строгая CPU/RAM-метрия для честного multi-participant benchmark.
- Workers для параллельной оценки.
- 3D renderer и полноценная 3D-физика.
- Проверки self-intersection и слишком близких несоседних участков.

Текущий формат точки уже готов для дальнейшего 3D:

```js
{ x, y, width, elevation }
```
