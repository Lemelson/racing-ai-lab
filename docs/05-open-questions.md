# Открытые решения перед программированием

Ни один вопрос не мешал создать структуру и план. Ниже указаны рекомендуемые ответы по умолчанию; их можно изменить до начала реализации.

| Вопрос | Рекомендуемый вариант по умолчанию | Почему |
|---|---|---|
| Что считаем главным результатом? | Generalization на закрытых трассах; скорость обучения — отдельный рейтинг. | Не позволяет победить простым запоминанием тренировочных трасс. |
| Разрешены ли ML-библиотеки? | Да, но одинаково всем и с полным manifest. Отдельно можно провести «from scratch» дивизион. | Запрет автора был частью его личного челленджа, а не технической необходимостью. |
| Какой алгоритм разрешён? | Любой, работающий через общий API и бюджет. | Тогда действительно сравнивается инженерное решение LLM. |
| Один язык или любой? | Один Rust-интерфейс для первой честной гонки. | Любой язык смешает качество алгоритма с overhead runtime и IPC. |
| Нужен ли человеческий участник? | После работающего baseline; не блокирует ChatGPT vs Gemini. | Сначала надо доказать корректность среды. |
| 2D или 3D? | 2D MVP, но replay и API проектируются независимо от renderer. | Это быстрее, понятнее и достаточно для обучения; 3D можно добавить позже. |
| Нужен ли GPU? | Не предполагать; выбрать по benchmark CPU vs MLX/MPS. | Маленькие сети могут быть быстрее на CPU. |
| Сколько машин? | Не фиксировать «250 как в ролике»; подобрать batch по throughput и общей памяти. | Размер популяции — hyperparameter, а не визуальное правило. |
| Как задавать трассу? | Геометрия + centerline + визуальная текстура. | Надёжнее пиксельных цветов и даёт точный progress. |
| Можно ли hard-code поведение? | Да, если оно использует только разрешённые наблюдения и декларируется. | В ролике ChatGPT это делал; запрет сделал бы сравнение другим. |
| Как общаться с LLM? | Сначала вручную, один экспортированный prompt и полный журнал; API-автоматизация позже. | Уменьшает инфраструктуру до проверки самой идеи. |
| Сколько повторов? | Финальное число определить benchmark времени; не менее нескольких seeds. | Одиночный прогон статистически ненадёжен. |
| Нужны ли столкновения машин? | Нет в benchmark; опционально в отдельном шоу-режиме. | Сравниваем вождение, а не случайные контакты. |

## Информация, которую полезно уточнить у владельца Mac

- точный объём unified memory;
- версия macOS;
- допустимая длительность одного обучения: минуты, часы или ночь;
- допустим ли нагрев/шум вентиляторов при длительной полной нагрузке;
- хочется ли в будущем публиковать видео или только смотреть локально;
- есть ли подписки/API-доступ к конкретным версиям ChatGPT и Gemini.

Эти ответы не меняют смысл проекта, но повлияют на batch size, лимиты и способ запуска.
