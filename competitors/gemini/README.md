# Gemini competitor

Зарезервированная рабочая область решения Gemini.

Версии хранятся отдельно:

- `v1/manifest.json`.

Текущий manifest описывает демонстрационную baseline-конфигурацию. В будущем Gemini получит:

- общую спецификацию среды;
- замороженный participant API;
- разрешённые training/validation tracks;
- общий prompt;
- тесты контракта;
- одинаковый вычислительный бюджет.

Gemini сможет изменять только эту папку и явно разрешённый lock/manifest зависимостей. Общая физика, scoring и чужие решения остаются read-only.

До старта сохраняются точное название модели, дата, prompt и число итераций общения.
