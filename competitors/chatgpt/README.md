# ChatGPT competitor

Зарезервированная рабочая область решения ChatGPT.

Версии хранятся отдельно:

- `v1/manifest.json`;
- `v2/manifest.json`.

Текущие manifests описывают демонстрационные baseline-конфигурации. В будущем ChatGPT получит:

- общую спецификацию среды;
- замороженный participant API;
- разрешённые training/validation tracks;
- общий prompt;
- тесты контракта;
- одинаковый вычислительный бюджет.

ChatGPT сможет изменять только эту папку и явно разрешённый lock/manifest зависимостей. Общая физика, scoring и чужие решения остаются read-only.

До старта сохраняются точное название модели, дата, prompt и число итераций общения.
